# 画面仕様

## 目的

HEXACO-PI-R の 60問版・100問版に回答し、性格全体の因子と下位尺度を確認できる PoC です。

以前のように外向性だけへ絞る仕様は採用していません。全体構成を表示し、その中に外向性も含めています。

## 画面構成と遷移

診断画面、診断結果画面、診断履歴画面を分けて表示します。同じ画面内に質問と結果を同時表示しません。

診断画面には次の領域があります。

- テスト切り替え: 60問版と100問版を選ぶ
- 進捗表示: 回答済み数、進捗バー、未回答への移動
- 質問パネル: 現在の質問と5件法の回答ボタン
- 操作: 回答のクリア、回答完了後の結果表示

診断結果画面には次の領域があります。

- 集計概要: 対象テストと集計済み因子数
- AI文章生成: テーマを選び、全因子・全下位尺度を含む文章を生成またはプロンプトをコピーする
- スコア概要: 因子スコアをコンパクトに一覧表示
- 結果詳細: 因子ごとに展開して下位尺度のスコアを確認
- 操作: 回答の見直し、再診断

診断履歴画面には次の領域があります。

- 完了した診断結果の一覧（実施日時、テスト種別、因子スコア）
- 保存済み結果の再表示
- 履歴の個別削除と全削除

## 診断履歴の保存

診断を完了した時点で、集計済みの因子・下位尺度スコアをブラウザーの `localStorage` に自動保存します。生成した診断レポートも診断・テーマごとに同じ履歴へ保存し、同じテーマで再生成した場合は、生成成功後に以前のレポートを上書きします。個々の設問への回答は「途中保存」を押した場合に限り、再開する質問位置とともに別データとして保存します。

- 保存上限は新しいものから50件
- サーバーへの送信と端末間同期は行わない
- 同じ診断の回答を見直して修正した場合は、既存履歴のスコアを更新する
- 途中保存データは60問版・100問版ごとに保持し、起動時は最後に保存したテストから再開する
- 診断完了時または回答のクリア時に、対象テストの途中保存データを削除する
- ブラウザーのデータ消去、シークレットモードの終了、別ブラウザーや別端末への移動では履歴を引き継がない
- 保存に失敗した場合は結果画面と履歴画面に通知する

## 回答の流れ

1. 60問版または100問版を選ぶ
2. 質問に5件法で回答する
3. 5段階の円形スケールから回答すると次の質問へ進む
4. 必要に応じて質問ドットから過去の質問へ戻る
5. 必要に応じて「ここでひと休み」を押し、回答と再開位置をブラウザーへ保存する
6. 全問回答すると診断結果画面へ自動的に遷移する
7. 必要に応じて診断画面へ戻り、回答を見直す

## 結果表示

診断結果画面の上部には、すべての因子の平均スコアと解釈ラベルをコンパクトに一覧表示します。その直後にAI文章生成を配置します。

詳しい結果では、因子ごとの項目を展開すると下位尺度を確認できます。各尺度には平均スコアと解釈ラベルを表示します。

60問版では6因子を表示します。100問版では6因子に加えて、利他性も表示します。

## AI文章生成とプロンプト作成

診断結果画面では、次の5テーマからプロンプトを作成できます。

- 総合診断
- 恋愛・パートナーシップ
- 仕事・適性
- 周囲から見たあなた
- あなたの取扱説明書

すべてのテーマで全因子・全下位尺度を使用します。ユーザーによる診断項目の選択は行いません。

「総合診断」「恋愛・パートナーシップ」「仕事・適性」「周囲から見たあなた」は、「テーマ選択」「このテーマでレポートを作る」の2ステップで操作します。作成したプロンプトをCloudflare Pages Functionへ送り、`@cf/google/gemma-4-26b-a4b-it`で文章を生成できます。送信は生成ボタンを押した場合だけ行います。生成結果はMarkdownとして画面内に表示し、ブラウザーの `localStorage` へ保存します。生成結果をコピーする操作は提供しません。

生成ボタンの下には「詳しいプロンプトを見る」を折りたたんで配置し、プロンプト全文の確認とコピーを提供します。通常の生成導線ではプロンプトの確認を必須にしません。

「あなたの取扱説明書」は文章テーマと生成導線を共有せず、画像生成用プロンプトのコピーを主操作として提供します。画像生成は行いません。

## モバイル対応

スマホ幅では1カラム表示に切り替えます。

- 回答ボタンは指で押しやすい高さにする
- 質問文は横にはみ出さないよう折り返す
- 質問ドットは狭い画面ではスクロール可能にする
- 診断画面と診断結果画面をそれぞれ1カラムで表示する
- 下位尺度は1列で表示する
- 因子スコアの概要は2列で表示し、AI文章生成より先に確認できるようにする
- AI文章生成が画面外にある間は固定ボタンで入口を示し、AI領域が見えたら固定ボタンを非表示にする
- AI文章生成はテーマ選択、生成の2ステップで完結させる
- AIテーマは2列を基本とし、画像テーマは1列分の幅で区別する
- プロンプトのコピー操作は画面幅いっぱいのボタンと完了メッセージでフィードバックする
- 生成中、生成失敗、生成完了の状態を同じ領域に表示する

## この PoC でまだ扱わないこと

- PDF 出力
- ユーザー管理
- 回答履歴の比較
- アプリ内での画像生成
- 医療・心理診断としての判定
