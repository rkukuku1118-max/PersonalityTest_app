# 画面仕様

## 目的

HEXACO-PI-R の 60問版・100問版に回答し、性格全体の因子と下位尺度を確認できる PoC です。

以前のように外向性だけへ絞る仕様は採用していません。全体構成を表示し、その中に外向性も含めています。

## 画面構成と遷移

診断画面、診断結果画面、診断履歴画面を分けて表示します。同じ画面内に質問と結果を同時表示しません。

診断画面には次の領域があります。

- テスト切り替え: 60問版と100問版を選ぶ
- 進捗表示: 回答済み数、進捗バー、未回答への移動
- 質問パネル: 現在の質問と5件法の回答ボタン
- 操作: 回答のクリア、回答完了後の結果表示

診断結果画面には次の領域があります。

- 集計概要: 対象テストと集計済み因子数
- AIプロンプト作成: テーマを選択し、全因子・全下位尺度を含むプロンプトをコピーする
- 結果一覧: 因子と下位尺度のスコア
- 操作: 回答の見直し、再診断

診断履歴画面には次の領域があります。

- 完了した診断結果の一覧（実施日時、テスト種別、因子スコア）
- 保存済み結果の再表示
- 履歴の個別削除と全削除

## 診断履歴の保存

診断を完了した時点で、集計済みの因子・下位尺度スコアをブラウザーの `localStorage` に自動保存します。個々の設問への回答は「途中保存」を押した場合に限り、再開する質問位置とともに別データとして保存します。

- 保存上限は新しいものから50件
- サーバーへの送信と端末間同期は行わない
- 同じ診断の回答を見直して修正した場合は、既存履歴のスコアを更新する
- 途中保存データは60問版・100問版ごとに保持し、起動時は最後に保存したテストから再開する
- 診断完了時または回答のクリア時に、対象テストの途中保存データを削除する
- ブラウザーのデータ消去、シークレットモードの終了、別ブラウザーや別端末への移動では履歴を引き継がない
- 保存に失敗した場合は結果画面と履歴画面に通知する

## 回答の流れ

1. 60問版または100問版を選ぶ
2. 質問に5件法で回答する
3. 回答すると次の質問へ進む
4. 必要に応じて質問ドットから過去の質問へ戻る
5. 必要に応じて「途中保存」を押し、回答と再開位置をブラウザーへ保存する
6. 全問回答すると診断結果画面へ自動的に遷移する
7. 必要に応じて診断画面へ戻り、回答を見直す

## 結果表示

診断結果画面では、下位尺度を動的に切り替えません。

すべての因子を表示し、各因子の下に下位尺度をすべて並べます。各尺度には平均スコアと解釈ラベルを表示します。

60問版では6因子を表示します。100問版では6因子に加えて、利他性も表示します。

## AIプロンプト作成

診断結果画面では、次の5テーマからプロンプトを作成できます。

- 総合診断
- 恋愛・パートナーシップ
- 仕事・適性
- 周囲から見たあなた
- あなたの取扱説明書

すべてのテーマで全因子・全下位尺度を使用します。ユーザーによる診断項目の選択は行いません。「あなたの取扱説明書」だけは、SNSで保存・共有しやすい縦長画像の生成をAIへ依頼します。

作成したプロンプトは内容を確認してからクリップボードへコピーできます。アプリから外部AIへ診断結果を自動送信しません。

## モバイル対応

スマホ幅では1カラム表示に切り替えます。

- 回答ボタンは指で押しやすい高さにする
- 質問文は横にはみ出さないよう折り返す
- 質問ドットは狭い画面ではスクロール可能にする
- 診断画面と診断結果画面をそれぞれ1カラムで表示する
- 下位尺度は1列で表示する
- AIプロンプト作成はテーマ選択、コピーの2操作で完結させる
- コピー操作は画面幅いっぱいのボタンと完了メッセージでフィードバックする

## この PoC でまだ扱わないこと

- PDF 出力
- ユーザー管理
- 回答履歴の比較
- アプリ内での診断文・画像の直接生成
- 医療・心理診断としての判定
